# Take-Home Starter Materials — "The Context Bundle"

This is the fake-but-realistic context for the take-home. It represents the
scattered knowledge of a small company ("Aperture Robotics") that lives across a
repo, some docs, and Slack.

## What's here
- `docs/` — five markdown docs (overview, deploy pipeline, on-call, onboarding,
  data warehouse). Some are explicitly noted as possibly stale.
- `services.json` — the structured "who owns what" data: services, owners, teams,
  repos, docs, Slack channels.
- `questions-last-week.md` — a log of the "where/who/how" questions people
  actually asked last week. This is your demand signal.

## Your task
See the take-home brief you were sent. In short: build a small tool, automation,
or agent that makes answering these questions faster — and **deploy it** so we
can run it. Cap yourself at 90 minutes. Use AI tooling freely.

Nothing here is precious. Reshape, re-index, or ignore parts of it as you see fit.
