# New Engineer Onboarding (the manual version)

This is the checklist we hand new engineers. It is almost entirely manual, which
is exactly the kind of thing we'd love to automate.

1. Get added to GitHub org (ask Platform owner).
2. Get added to PagerDuty (ask whoever is on-call).
3. Clone `atlas-api`, run `make dev`. If it fails, ask in #eng-help.
4. Read `deploy-pipeline.md` before you ship anything.
5. Find out who owns the thing you're working on — check `services.json`.
6. Book 1:1s with each team lead (Platform, Growth, Ops). Nobody tells you to do
   this; you just have to know.

Half of onboarding is figuring out **who to ask**. That's the real cost.
